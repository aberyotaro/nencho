# nencho

年末調整の申告書PDFに、設定ファイルの値を書き込むツールです。出力するのは次の2枚です。

- 令和9年分 給与所得者の扶養控除等（異動）申告書
- 令和8年分 給与所得者の基礎控除申告書 兼 配偶者控除等申告書 …（基礎控除の欄のみ）

## 使い方

```sh
cp config.example.toml config.toml   # 空欄を埋める
./run.sh                             # out/ にPDFができる
```

給与所得、合計所得金額、基礎控除額は、給与の収入金額から令和8年分の表で計算します。

## 必要なもの

Python 3.11以上、または uv。依存は PyMuPDF だけで、初回の実行時に入ります。

## 制限

- マイナンバーの欄は出力しません。
- 書き込む位置は `forms/` のPDFに合わせています。別の版の様式では位置がずれます。
- フォントは同梱の BIZ UDPゴシック（SIL Open Font License）です。
